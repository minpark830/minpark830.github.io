## The app

FotoMagic is a photo editor in the browser. Users sign up and sign in, upload an image, adjust its brightness, contrast, gamma, and opacity, or turn it to grayscale, and the server does the processing with OpenCV.

The React front end, built with Vite, talks to a Flask REST API that handles sign-in with JSON Web Tokens and does the image processing. User records live in MongoDB and image files in Azure Blob Storage.

I set up three GitHub Actions workflows:

- **CI checks** install the front end with `npm ci`, run ESLint and Prettier, and build for production, so every pull request shows whether it lints and builds before anyone reviews it.
- **Front end** builds the React app and deploys it to Azure Static Web Apps. Each pull request gets its own preview environment, which closes when the pull request does.
- **API** packages the Flask app and deploys it to Azure App Service. The deploy job signs in to Azure with OpenID Connect rather than a stored client secret.

## The end-to-end test

The Cypress test follows the project's core user story: as a user, I want to upload an image and apply basic effects without needing advanced tools. It signs in as a test user, uploads a fixture image on the editor page, moves the brightness, gamma, contrast, and opacity sliders, and checks each value.

Range inputs need special handling. React tracks an input's value through its own property setter, so a test can't simply type into a slider. The custom command sets the value with the browser's native setter, then dispatches the input and change events that React listens for.

## Code quality

ESLint runs with the React, React Hooks, and Cypress plugins, and Prettier keeps formatting consistent. Both run in the CI checks, so a style problem fails the pull request instead of reaching review.

## My part

The three workflows, the Cypress test, and the ESLint and Prettier setup are mine, along with most of the architecture docs. I also built parts of the image editor page with a teammate. In all, 102 of the team's 265 commits.
